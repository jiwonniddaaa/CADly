# CADly : 멀티에이전트 기반 건축 평면 설계 지원 시스템
**CADly** 사용자의 설계 의도를 기반으로 기획, 생성, 검증, CAD 출력까지 연결하는 멀티에이전트 기반 건축 설계 지원 시스템입니다.

## ✅ Core Features
- 레퍼런스 기반 설계:
   이미지 + 평면 유형 + 설계 포인트 제공
- 자동 기획 구조화:
   공간 관계 및 면적 자동 계산
- 인터랙티브 설계 수정:
   자연어 기반 실시간 수정
- 설계 검증:
   구조 및 규칙 기반 검증
- CAD 출력:
   실제 사용 가능한 DXF 파일 생성
